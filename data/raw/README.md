# Raw Dataset

## Dataset
NSL-KDD Dataset

## Source
The NSL-KDD dataset is an improved version of the KDD Cup 1999 dataset developed by the University of New Brunswick (UNB).

## Files
- KDDTrain+.txt
- KDDTest+.txt

## Description
The dataset contains network traffic records used for intrusion detection research. Each record consists of 41 features describing a network connection along with a target label representing the traffic type.

## Features
The dataset includes:
- Basic TCP connection features
- Content features
- Traffic features
- Host-based traffic features

Total Features: 41

## Target Labels
The dataset classifies network traffic into:
- Normal
- DoS (Denial of Service)
- Probe
- R2L (Remote to Local)
- U2R (User to Root)

## Important
The files in this directory are the original dataset and must not be modified. Data cleaning, preprocessing, encoding, feature selection, and scaling will be performed during later stages of the project.
